# Datos de ejemplo

`medicamentos-ejemplo.csv` es un panel **ficticio** creado para el curso: 10 medicamentos de marca observados de 2019 a 2023, con la entrada de genéricos escalonada en distintos años.

Los datos están muy limpios a propósito. Sirven para practicar, no para sacar conclusiones: cualquier resultado que salga de aquí es irreal.
